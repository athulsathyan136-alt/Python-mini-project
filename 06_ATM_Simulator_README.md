🏧 ATM Simulator

A simple beginner-friendly ATM Simulator built with Python. This project simulates basic ATM operations such as PIN authentication, checking balance, depositing money, and withdrawing money.

📌 Features
🔐 PIN authentication
💰 Check account balance
💵 Deposit money
💸 Withdraw money
⚠️ Insufficient balance validation
❌ Invalid PIN and option handling
🛠️ Technologies Used
Python 3
📂 Project Structure
ATM-Simulator/
│
├── atm.py
└── README.md
▶️ How to Run
Install Python 3.
Clone this repository.
Open the project folder in your terminal.
Run:
python atm.py
Enter the PIN when requested.

Default PIN: 9961
