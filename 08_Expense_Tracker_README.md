# 💰 Expense Tracker

A simple Python program that allows users to enter their expenses and calculates the total amount spent.

## Features

* Enter expenses
* Calculate total expenses
* Display total spending

## Technology

* Python 3

## How to Run

```bash
python expense_tracker.py
```

## Example

```text
Expense Tracker

Enter first expense: ₹100
Enter second expense: ₹250
Enter third expense: ₹150

Total Expenses: ₹500
```
