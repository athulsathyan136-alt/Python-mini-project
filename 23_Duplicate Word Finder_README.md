Duplicate Word Finder

A simple Python program that analyzes user-provided text, counts the frequency of each word, and identifies duplicate words.

🚀 Features
Accepts text from the user
Converts text to lowercase
Removes common punctuation
Counts the frequency of each word
Finds duplicate words
Displays how many times each duplicate appears
Shows a message when no duplicate words are found
Displays an analysis completion message
🛠️ Technologies Used
Python 3
Strings
Lists
Dictionaries
For Loops
If-Else Statements
User Input

▶️ How to Run
Install Python 3.
Clone this repository.
Open the project folder in VS Code.
Run the program:
python duplicate_word_finder.py
Enter your text when prompted.
