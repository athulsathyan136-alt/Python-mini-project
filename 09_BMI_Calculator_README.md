🧮 BMI Calculator

A simple Python BMI Calculator that calculates a person's Body Mass Index (BMI) using their weight and height. The program also displays a basic BMI category based on the calculated result.

Features
Takes weight as input
Takes height as input
Calculates BMI
Rounds the result
Displays a BMI category
Technology
Python 3
How to Run
python bmi_calculator.py
Example
BMI Calculator

Enter your height (m): 1.75
