# 🔐 Username Generator

A simple Python program that generates random and unique usernames using a combination of adjectives, the user's name, animals, and random numbers.

## 🚀 Features

* 🔤 Uses the user's name
* 🎲 Generates random usernames
* 🐺 Includes different animal names
* ✨ Includes descriptive adjectives
* 🔢 Adds random numbers
* 🔁 Generates 5 unique usernames
* ❌ Handles empty name input

## 🛠️ Technologies Used

* Python 3
* `random` module
* Lists
* Sets
* Strings
* Loops
* Conditional statements
* User input

## ▶️ How to Run

Make sure Python 3 is installed.

Open the terminal inside the project folder and run:

```bash
python username_generator.py
```
