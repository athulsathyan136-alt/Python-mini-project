# 🔄 Unit Converter

A simple Python command-line application that converts values between different units such as distance, temperature, and weight.

## 🚀 Features

* Kilometers to miles
* Miles to kilometers
* Celsius to Fahrenheit
* Fahrenheit to Celsius
* Kilograms to pounds
* Pounds to kilograms
* Simple menu-based interface
* Supports decimal values

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python 26_unit_converter.py
```

4. Select a conversion option.
5. Enter the value you want to convert.

## 📊 Example

```text
🔄 Unit Converter
-----------------
1. Kilometers → Miles
2. Miles → Kilometers
3. Celsius → Fahrenheit
4. Fahrenheit → Celsius
5. Kilograms → Pounds
6. Pounds → Kilograms

Choose an option (1-6): 3
Enter value: 25

25°C = 77.00°F
```
