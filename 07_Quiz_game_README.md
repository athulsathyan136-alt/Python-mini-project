# Python Quiz Game

A simple quiz game created using Python. The program asks three questions, checks the answers, and displays the final score.

## Features

* 3 simple questions
* Checks answers
* Calculates score
* Displays final result

## Technology

* Python 3

## How to Run

```bash
python quiz.py
```

## Example

```text
Python Quiz

1. What is 2 + 2? 4
Correct!

2. What language are we learning? Python
Correct!

3. What is the Python file extension? .py
Correct!

Your score: 3 / 3
```
