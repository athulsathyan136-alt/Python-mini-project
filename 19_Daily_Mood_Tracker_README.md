# 😊 Daily Mood Tracker

A simple Python command-line application that allows users to record their daily mood and save it to a history file.

## 🎯 Project Objective

The goal of this project is to practice basic Python programming and file handling by creating a small daily mood-tracking application.

## ✨ Features

* Enter your mood for the day
* Automatically records the current date
* Saves mood history to a text file
* Keeps previous entries instead of deleting them

## 🛠️ Technologies

* Python 3
* `datetime`
* File handling

## 📂 Project Structure

```text
daily-mood-tracker/
│
├── main.py
├── README.md
└── mood_history.txt
```

## ▶️ How to Run

Open the project in VS Code.

Run:

```bash
python main.py
```

Enter your mood when asked:

```text
😊 Daily Mood Tracker
How are you feeling today? Happy
```

The program will save the entry:

```text
2026-08-13 - Happy
```

## 📄 Mood History

The application stores previous moods in:

```text
mood_history.txt
```

Example:

```text
2026-08-13 - Happy
2026-08-14 - Excited
2026-08-15 - Tired
```
