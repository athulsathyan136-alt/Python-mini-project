A simple Weather App built with Python that fetches real-time weather information using the *Open-Meteo API*. Users can enter a city name, and the application displays the current temperature for that location.

## 🚀 Features

- Search weather by city name
- Display current temperature
- Uses Open-Meteo Geocoding API
- Uses Open-Meteo Weather API
- No API key required
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3
- Requests library
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## ▶️ Installation

1. Install Python 3.
2. Install the required library:

bash
pip install requests


3. Run the application:

bash
python 05-Weather-App.py
