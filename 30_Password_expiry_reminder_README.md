# 🔐 Password Expiry Reminder

A simple Python project that calculates when a password will expire and shows how many days are remaining.

## 🚀 Features

- Enter password creation date
- Set password validity period
- Calculate password expiry date
- Show remaining days
- Detect expired passwords
- Handle invalid date formats

## 🛠️ Technologies Used

- Python 3
- `datetime` module

==============================

Enter password creation date (YYYY-MM-DD): 2026-08-01
Enter password validity in days: 30
