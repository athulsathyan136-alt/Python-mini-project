# 💡 Random Quote Generator

A simple Python command-line application that randomly selects and displays a motivational or programming-related quote each time it runs.

## 🚀 Features

* Contains multiple motivational and programming quotes
* Selects a quote randomly
* Displays a different quote on each run
* Simple command-line interface
* Easy to customize with your own quotes

## 🛠️ Technologies Used

* Python
* `random` module

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python 27_random_quote_generator.py
```

## 📊 Example Output

```text

-------------------------

💬 Your Quote:
"Build projects, not just tutorials."
```
