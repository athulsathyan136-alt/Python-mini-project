# 🔐 Password Strength Checker

A simple Python command-line application that analyzes a password and estimates its strength based on common password characteristics.

## 🎯 Project Objective

This project helps beginners practice Python while building a small cybersecurity-related utility.

The program checks whether a password contains:

* Minimum length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

It then calculates a score and classifies the password as **Weak**, **Medium**, or **Strong**.

## 🛠️ Technologies

* Python 3
* Python Standard Library
* `string` module

## ▶️ How to Run

Make sure Python is installed.

Run the program:

```bash
python main.py
```

Enter a password when prompted.

```text

```

## 📊 Strength Levels

| Score | Strength  |
| ----- | --------- |
| 0–2   | 🔴 Weak   |
| 3–4   | 🟡 Medium |
| 5     | 🟢 Strong |
