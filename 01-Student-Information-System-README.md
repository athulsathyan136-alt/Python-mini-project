# 🎓 Student Information System

A simple Python application to manage student information and calculate total marks and average marks.

---

## 📖 About

This project allows users to enter student details, store subject marks, calculate the total marks, and display the average marks. It is a beginner-friendly Python project designed to practice variables, input/output, calculations, and functions.

---

## ✨ Features

- 👤 Enter Student Name
- 🆔 Enter Roll Number
- 🎂 Enter Age
- 📚 Enter Course
- 🐍 Enter Python Marks
- 🗄️ Enter SQL Marks
- 🤖 Enter AI Marks
- ➕ Calculate Total Marks
- 📊 Calculate Average Marks
- 📋 Display Student Details

---

## 🛠️ Technologies Used

- Python 3
