# ✂️🪨📄 Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python.  
Play against the computer and see who wins each round.

## 📌 Description

The program:

- Lets the user choose rock, paper, or scissors
- Randomly selects the computer’s choice
- Compares both choices and decides win / lose / tie
- Allows the user to play multiple rounds or quit

This project is designed to practice basic Python concepts like user input, conditionals, loops, and the `random` module.

## ✨ Features

- 🎮 Interactive command-line game  
- 🤖 Random computer opponent  
- ✅ Win / lose / tie logic  
- 🔁 Play multiple rounds  
- 🚪 Option to quit anytime  

## 🛠️ Technologies Used

- Python 3  
- Built-in `random` module  

## 🚀 How to Run

1. Make sure Python 3 is installed:
   ```bash
   python --version
   ```
2. Run the game:
   ```bash
   python 16_Rock_Paper_Scissors.py
   ```
