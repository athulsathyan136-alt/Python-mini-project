# 📊 File Size Analyzer

A simple Python project that scans a folder, displays the size of each file, and calculates the total number of files and total folder size.

## 🚀 Features

* Enter any folder path
* Detect files automatically
* Display individual file sizes
* Calculate total number of files
* Calculate total file size
* Display file sizes in KB

## 🛠️ Technologies Used

* Python
* `os` module

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python 25_file_size_analyzer.py
```

4. Enter the folder path when prompted.

Example:

```text
Enter folder path: E:\Python_mini_project
```
