# 📝 Simple To-Do List

A beginner-friendly command-line To-Do List application built with Python.

## 📌 Features

* Add tasks
* View tasks
* Remove tasks
* Simple menu system
* Runs directly from the terminal

## 🛠️ Technologies

* Python 3
* VS Code
* Git
* GitHub


## 💻 Example

```text
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Remove Task
4. Exit

Choose an option: 1
Enter a task: Learn Python
Task added successfully!

Choose an option: 2

Your Tasks:
1. Learn Python
```
