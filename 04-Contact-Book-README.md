# 📒 Contact Book

A simple Contact Book application built with Python. This command-line program allows users to store and manage contacts by adding, viewing, searching, and deleting contact information.

## 🚀 Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Delete contacts
- Simple menu-driven interface

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure


04-Contact-Book.py
04-Contact-Book-README.md


## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the program:

bash
python 04-Contact-Book.py
