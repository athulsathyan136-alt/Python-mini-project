🌦️ Weather Outfit Advisor

A simple Python program that recommends suitable clothing based on the temperature and whether it is raining.

🚀 Features
Accepts temperature in Celsius
Checks whether it is raining
Displays the entered weather information
Provides outfit recommendations
Beginner-friendly Python project

🛠️ Technologies
Python 3
