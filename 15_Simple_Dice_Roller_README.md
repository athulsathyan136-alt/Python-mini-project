# 🎲 Simple Dice Roller

A beginner-friendly Python command-line application that simulates rolling a six-sided dice.

## 📌 Description

The Simple Dice Roller uses Python's built-in `random` module to generate a random number between 1 and 6.

After each roll, the user can choose to roll the dice again or exit the program.

This project is designed to practice basic Python programming concepts and build a simple interactive command-line application.

## ✨ Features

* 🎲 Random dice roll
* 🔢 Generates numbers from 1 to 6
* 🔄 Roll the dice multiple times
* 👤 Interactive user input
* 🚪 Exit option
* 💻 Command-line interface

## 🛠️ Technologies Used

* Python 3
* VS Code
* Git
* GitHub
