# 🩺 Health Details – Python

A simple beginner-friendly Python project that collects basic health-related information from the user and calculates their Body Mass Index (BMI).

## 📌 Features

* Enter name
* Enter age
* Enter weight
* Enter height
* Calculate BMI
* Display health details

## 🛠️ Technology Used

* Python 3

## 📂 Project Structure

```text
Health-Details/
│
├── health_details.py
└── README.md
```

## ▶️ How to Run

Make sure Python 3 is installed.

Run the program:

```bash
python health_details.py
```

## 💻 Example

```text
===== Health Details =====

Enter your name: Amal
Enter your age: 22
Enter your weight (kg): 90
Enter your height (m): 1.75

===== Your Details =====
Name: Amal
Age: 22
Weight: 90.0 kg
Height: 1.75 m
BMI: 29.39
```

This project is created for **Python programming practice and educational purposes**. It is not intended to provide medical advice or diagnosis.
