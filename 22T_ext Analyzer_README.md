Text Analyzer

A simple Python project that analyzes user-provided text and displays useful statistics.

🚀 Features
🔤 Counts total characters
📝 Counts total words
🔡 Counts vowels
📄 Counts sentences
🏆 Finds the longest word
✅ Displays a clear analysis summary
🛠️ Technologies Used
Python 3
String manipulation
Loops
Conditional statements
Functions and built-in methods
User input

▶️ How to Run
Clone the repository:
git clone YOUR_GITHUB_REPOSITORY_URL
Open the project folder:
cd Text_Analyzer
Run the program:
python text_analyzer.py
