# ⏰ Simple Countdown Timer

A beginner-friendly Python command-line application that counts down from a number of seconds entered by the user.

## 📌 Description

The Simple Countdown Timer is a small Python project created to practice fundamental programming concepts.

The user enters a number of seconds, and the program counts down one second at a time until it reaches zero. When the countdown finishes, the program displays a completion message.

## ✨ Features

* ⏱️ Custom countdown duration
* 🔢 User input
* ⏳ Real-time countdown
* ⏰ Completion message
* 💻 Command-line application
* 🐍 Uses Python's built-in `time` module

## 🛠️ Technologies Used

* Python 3
* VS Code
* Git
* GitHub
