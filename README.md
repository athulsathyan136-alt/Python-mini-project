# 🎯 Number Guessing Game

A simple Python command-line game where the computer randomly selects a number between 1 and 10, and the player tries to guess it.

## 🛠️ Technologies

* Python
* VS Code

## 🎮 Example

```text
🎯 Number Guessing Game
-----------------------
Guess a number between 1 and 10

Enter your guess: 7

🎉 Correct! You won!
```
