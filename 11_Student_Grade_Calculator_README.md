# 🎓 Student Grade Calculator

A simple Python project that calculates a student's total marks, average, grade, and pass/fail result.

This project is designed for beginners who are learning **Python, VS Code, Git, GitHub, and Docker**.

## ✨ Features

* 👤 Enter student name
* 📝 Enter marks for 5 subjects
* ➕ Calculate total marks
* 📊 Calculate average
* 🏆 Calculate grade
* ✅ Display pass/fail result
* 🐳 Run the application using Docker

## 🛠️ Technologies Used

* Python

Example:

```text
🎓 Student Grade Calculator
---------------------------
Enter student name: Amal
Enter marks for subject 1: 85
Enter marks for subject 2: 90
Enter marks for subject 3: 78
Enter marks for subject 4: 88
Enter marks for subject 5: 92
```

Example result:
-----
📋 Result
---------------------------
Student : Amal
Total   : 433.0/500
Average : 86.60
Grade   : A
Result  : PASS
```
