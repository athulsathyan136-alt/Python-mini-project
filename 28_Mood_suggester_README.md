# 😊 Mood Based Activity Suggester

A simple Python program that suggests an activity based on the user's current mood.

The program asks the user how they are feeling and randomly selects an activity that may be suitable for that mood.

## 🚀 Features

* 😊 Happy mood suggestions
* 😢 Sad mood suggestions
* 😴 Tired mood suggestions
* 😰 Stressed mood suggestions
* 😐 Bored mood suggestions
* 🎲 Random activity selection
* ❌ Invalid input handling
* 🖥️ Simple command-line interface

## 🛠️ Technologies Used

* Python 3
* Dictionaries
* Lists
* `random` module
* `if/elif` conditions
* User input
* Functions from Python's standard library

Make sure Python is installed.

Run the following command in the terminal:

```bash
python mood_suggester.py
```
