# 📁 File Extension Analyzer

A simple Python project that analyzes a folder and counts how many files belong to each file extension.

## 🚀 Features

* Enter any folder path
* Detect file extensions automatically
* Count files by extension
* Identify files without an extension
* Display a simple file summary

## 🛠️ Technologies Used

* Python
* `os` module

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python 24_file_extension_analyzer.py
```

4. Enter the folder path when prompted.

Example:

```text
Enter folder path: E:\Python_mini_project
```

## 📊 Example Output

```text
📁 File Extension Analyzer
--------------------------
Enter folder path: E:\Python_mini_project

📊 File Summary
----------------
.py: 25 file(s)
.md: 24 file(s)
```
