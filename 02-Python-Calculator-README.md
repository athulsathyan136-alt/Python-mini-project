# 🧮 Python Calculator

A simple menu-driven calculator built using Python. It performs basic arithmetic operations based on the user's choice.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly menu
- Handles invalid choices

## Technologies Used

- Python 3

## How to Run

1. Download the project.
2. Open the project in VS Code.
3. Run the program:

```bash
python Calculator.py
```

## Sample Output

```
Choose an Operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1
Enter first number: 10
Enter second number: 20

Result: 30
```
